# Network Security Lab

![GitHub repo size](https://img.shields.io/github/repo-size/IsaiAV/network-security-lab)
![MIT License](https://img.shields.io/badge/license-MIT-green)
![Build Status](https://img.shields.io/badge/status-active-brightgreen)

This is a modular, real-world cybersecurity lab covering essential tools in:

- Firewalls (`iptables`, Cisco ACLs)
- IDS/IPS Systems (Suricata, OSSEC)
- VPN Configs (OpenVPN, IPSec)

Each folder contains real configs, learning notes, and practical use cases.

---

## Repo Structure

| Category      | Contents                            |
|---------------|-------------------------------------|
| `firewalls/`  | `iptables`, `Cisco ACL` configs     |
| `ids_ips/`    | Suricata + OSSEC custom rules       |
| `vpn_configs/`| OpenVPN + IPSec setup examples      |

---

## Use Cases

- Build a personal home security lab
- Study configs for certs (Security+, CySA+, CCNA Sec)
- Use for interviews, portfolios, and demos
