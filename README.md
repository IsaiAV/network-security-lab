This is a modular, real-world cybersecurity lab covering essential tools in:

- Firewalls (`iptables`, Cisco ACLs)
- IDS/IPS Systems (Suricata, OSSEC)
- VPN Configs (OpenVPN, WireGuard)

Each folder contains real configs, learning notes, and practical use cases.

---

## Repo Structure

| Category      | Contents                            |
|---------------|-------------------------------------|
| `firewalls/`  | `iptables`, `Cisco ACL` configs     |
| `ids_ips/`    | Suricata + OSSEC custom rules       |
| `vpn_configs/`| OpenVPN + WireGuard setup examples  |
| `network_logs/` | Sample alerts and log output      |

---

## Use Cases

- Build a personal home security lab
- Study configs for certs (Security+, CySA+, CCNA Sec)
- Use for interviews, portfolios, and technical walkthroughs

---

## Tools Covered

- `iptables`, `ufw`, `Cisco ACL`
- `Suricata`, `OSSEC`, `Fail2Ban`
- `OpenVPN`, `WireGuard`
